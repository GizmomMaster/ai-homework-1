> Реализовать консольный проект ai-homework-1 для сканирования md файлов в указанной папке.
- Технический стек
  - только Node.js
Папка с файлами для сканирования: ai-homeworks/ai-homework-1/ecto-1-kb-main
- Функционал:
  - Найти все файлы в указанной папке с разрешение .md
  - Извлечь все ссылки указанные в этих файлах: текстовые, ulrs, полные и относительные ссылки на другие файлы.
  - Проверить локальные ссылки на существование файлов, а внешние HTTP-ссылки — на доступность (отправить сначало HEAD, если ответа не будет то GET запрос).
  - Вывести в консоль отчёт в виде таблицы со списком ссылок и статус-кодами. Пометить зеленым цветом успешные, красным сломанные ссылки.
  - Реализовать в проекте возможность его запуска с выводом только слоамнных ссылок.
  - Сформировать readme файл с инструкцией по запуску проекта.
- Дополнительные условия
  - Таймаут по HTTP-запросам считаем равным 30 секундам, если ответа нет, значит ссылка сломана.
  - 4хх и 5хх коды ответов, считаем неуспешными, значит ссылка сломана.
  - Относительные пути к файлам ищем от файла в котором эта ссылка была найдена. Поэтому для относительных путей нужно запоминать пуст файла, в котором она была найдена, для корректной проверки.
