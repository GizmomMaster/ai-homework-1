# ai-homework-1

Консольная утилита на Node.js для проверки ссылок в markdown-файлах базы знаний.

## Что делает

1. Рекурсивно находит все `.md` файлы в указанной папке (по умолчанию — `ecto-1-kb-main`).
2. Извлекает из них все ссылки: обычные markdown-ссылки и изображения, ссылки по сноскам, автоссылки в `<>` и голые url в тексте.
3. Проверяет:
   - **локальные ссылки** (относительные и абсолютные пути к файлам) — на существование файла на диске;
   - **внешние HTTP(S)-ссылки** — на доступность: сначала отправляется `HEAD`-запрос, и если ответа нет (таймаут/сетевая ошибка) или сервер не поддерживает `HEAD` (код 405), выполняется `GET`-запрос. Таймаут — 30 секунд. Коды ответа 4xx и 5xx считаются неуспешными.
4. Выводит в консоль таблицу со списком всех найденных ссылок и их статусами: успешные — зелёным, сломанные — красным.

Ссылки на другие схемы (`mailto:`, `tel:` и т.п.) выводятся в отчёте, но не проверяются.

## Требования

- Node.js версии 18 и выше (используется встроенный `fetch`).
- Внешние зависимости не требуются — только стандартная библиотека Node.js.

## Запуск

```bash
node src/index.js
```

По умолчанию сканируется папка `ecto-1-kb-main` в корне проекта. Чтобы указать другую папку, передайте путь к ней первым аргументом:

```bash
node src/index.js path/to/folder
```

Либо через npm-скрипт:

```bash
npm start
```

## Код завершения

Утилита завершается с кодом `1`, если среди проверенных ссылок найдены сломанные, и с кодом `0`, если все ссылки успешны — это удобно для использования в CI.
